# 当前阶段计划

## 阶段
大一结束前 - 大二开学前

## 总目标
建立 CS 基础资产：算法、语言基础、GitHub、项目、英文 README、每周复盘。

## 当前优先级

### P0：编程基础
- C 语言基础巩固
- Python 基础巩固
- 能独立写小程序解决问题

### P1：俄语学习
- 掌握B1级别词汇
### P2：算法训练
- LeetCode 50-100 题
- 重点：数组、字符串、哈希表、双指针、栈、队列、链表、二分、递归

### P3：Git / GitHub
- 学会 commit、branch、README、项目结构
- 每周至少 3 次 commit

### P4：项目
- 完成一个 Python 工具项目
- 启动一个 Web 全栈项目雏形
- 搭建个人主页

### P5：英语技术表达
- 每个项目都写英文 README
- 每周积累 10 个技术英语表达

## 暂时不优先
- 复杂框架
- 过早刷竞赛难题
- 太多兼职
- 同时开多个大项目
- 追逐太多方向
